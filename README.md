## ✍️ Things I keep repeating on LinkedIn

- [x] Measure first, optimize second. Not every re-render is a problem.
- [x] Server cache is not client state.
- [x] Prefer `unknown` over `any`.
- [x] Add the right indexes for your queries, not one on every column.
- [x] Paginate for real data volumes.
- [x] Keep CPU-heavy work off the event loop.
